# LibreEvolve

Evolve code. Show the evidence.

An open-source workbench for inspectable code-evolution experiments.
**Engineering preview: bounded Python bin-packing optimization with Codex OAuth.**

Start with a small Python seed, search for changes, and inspect the candidate,
its named checks and saved run artifacts. Improvement is not guaranteed;
unchanged and unsuccessful experiments are useful outcomes to report honestly.

- [Explore the public project](https://github.com/LibreEvolve/libreevolve)
- [Run the preview](https://github.com/LibreEvolve/libreevolve/blob/main/docs/alpha-quickstart.md)
- [Read the artifact contract](https://github.com/LibreEvolve/libreevolve/blob/main/docs/run-artifacts.md)
- [Contribute](https://github.com/LibreEvolve/libreevolve/blob/main/docs/development.md)

Offline setup and seed-only checks are separate from a live model request.
Candidate Python runs with host access, not in a security sandbox. Subscription
usage may be unknown; local call and runtime limits are not hard spending caps.
Finite training and held-out checks do not prove universal correctness or optimality.

For public preview questions, search the
[product issues](https://github.com/LibreEvolve/libreevolve/issues) before opening
a sanitized report. Do not post credentials, OAuth files or private source.
