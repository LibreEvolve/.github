# Getting help

Check the affected repository's README and documentation first. Repository-local
support instructions take precedence over this shared default.

## Public engineering preview

Read the [quickstart](https://github.com/LibreEvolve/libreevolve/blob/main/docs/alpha-quickstart.md),
then search [existing product issues](https://github.com/LibreEvolve/libreevolve/issues).
For a non-sensitive question or reproducible bug, open an issue there and include:

- The public commit or version, Python version and operating system.
- The command and expected versus actual behavior.
- A minimal example you are permitted to publish.
- Whether the observation came from an offline check or an authorized live run.

Do not paste API keys, OAuth files, account details, raw prompts, full run
directories or private candidate source. Review every attachment before posting.
Usage or billing uncertainty should be stated as unknown, not filled in as zero.

## Other repositories and sensitive reports

Use the affected repository's existing access controls and reporting instructions.
Do not post private-repository problems in the public product tracker. If you
cannot identify an authorized private channel for sensitive information, do not
post the details publicly. This page does not create a private reporting channel.

The issue tracker is not an emergency service or a billing-support channel.
No response-time commitment or paid support service is offered here.
